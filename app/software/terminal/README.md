# 终端模拟器

## 功能介绍

轻量系统命令执行窗口，采用浅色工具栏与深色输出区，支持实时显示标准输出、红色错误输出、运行状态、退出码和耗时。

- 工作目录输入、目录选择、`cd` / `cd /d` 切换。
- 多行命令输入、停止当前命令及其子进程。
- 最近 100 条命令的会话历史、输出自动滚动开关、清屏与 UTF-8 日志导出。
- UTF-8、系统默认、GBK 输出编码选择。

## 使用方法

1. 在主程序中找到“终端模拟器”，点击运行；也可双击插件目录内的 `VBS运行.vbs` 独立启动。
2. 默认工作目录为当前用户主目录；可在目录栏输入路径后回车或点击“切换”，也可点击“浏览…”。
3. 输入命令，点击“执行命令”或按 **Ctrl+Enter**。普通回车用于换行。Windows 使用 CMD 语法，例如 `dir`、`echo 你好`、`where python`。
4. 长时间任务可以点击“停止”。执行期间禁止重复启动和切换目录，输入区仍可编辑下一条命令。
5. 使用 **Alt+↑ / Alt+↓** 回看历史命令，**Ctrl+L** 清屏，**Ctrl+A** 全选输入。点击“导出日志”保存当前保留的输出。

内置命令：`exit` / `quit` 关闭窗口；`clear` / `cls` 清屏；单独执行 `cd "含空格的目录"` 或 `cd /d 目录` 保留工作目录。

## 配置说明

- 只使用 Python 标准库，无需安装额外依赖；Python 环境须包含 tkinter。
- 在主程序中启动时使用设置页选定的 Python。独立 VBS 启动优先寻找安装目录或源码仓库内的嵌入式 Python，再回退系统 `pythonw`，不读取主程序选择的自定义解释器。
- `pip`、`pip3`、`python -m pip`、`python3 -m pip` 开头的命令会绑定插件当前 Python（pythonw 会选用同目录 python.exe），不自动添加升级、安装位置或免确认参数。
- 包索引由 pip 自身配置或命令参数决定；需要镜像时可明确指定 `-i https://pypi.tuna.tsinghua.edu.cn/simple`。
- `config.json` 为公开空模板；当前版本无需持久化设置，不保存历史命令、工作目录或日志。日志仅在用户主动导出时写入所选位置。

## 注意事项

- 请谨慎执行删除、移动等会修改文件的命令。
- 命令执行权限受当前 Windows 用户权限限制。
- 这是命令执行窗口，未提供交互式标准输入或伪终端；不适用于 Python REPL、SSH 密码输入、全屏编辑器或执行中确认提示。此类任务请使用系统终端。
- 每次执行使用新的命令进程。单独的 `cd` 会保留目录；`set` 等环境变更不会跨次执行保留。多行命令在同一批处理中执行，支持管道和重定向；退出码遵循 CMD 的批处理规则。
- 命令在临时 `.cmd` 文件中执行，结束后自动删除；`for` 循环变量须使用批处理写法（例如 `%%i`）。关闭窗口或点击停止会正常触发清理，插件进程被外部强杀时临时文件可能残留。
- 默认采用 UTF-8。旧式程序输出乱码时，执行前选择“GBK”或“系统默认”；程序自己固定的输出编码可能仍需在其参数中设置。该窗口不渲染 ANSI 光标控制或彩色转义序列。
- 输出区只保留最近 12,000 行且最多 1,000,000 字符；大量输出时旧内容会被截断，导出仅包含当前保留内容。
- “停止”在 Windows 使用进程树终止，可能中断正在写入的文件；关闭窗口时若仍有任务会先询问，再停止任务。命令主动脱离进程树启动的外部应用可能需要单独关闭。
- 历史命令只保留在内存中，但命令和输出可能包含敏感信息，分享导出日志前请自行检查。
